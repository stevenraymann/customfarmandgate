# Deployment Checklist for Custom Farm and Gate

## Pre-Deployment

- [ ] Rename `customfarmandgate.html` to `index.html`
- [ ] Update sitemap.xml with actual domain name
- [ ] Review all phone numbers are correct (251-485-5686)
- [ ] Test website locally in browser
- [ ] Test mobile responsiveness
- [ ] Verify all links work

## Azure Deployment

- [ ] Create Azure App Service or Static Web App
- [ ] Configure deployment method (Git, GitHub, or direct upload)
- [ ] Upload all files to Azure
- [ ] Verify deployment successful
- [ ] Test website at Azure URL (*.azurewebsites.net)

## Domain Configuration

- [ ] Purchase/configure customfarmandgate.com domain
- [ ] Add custom domain in Azure
- [ ] Update DNS A record or CNAME as specified by Azure
- [ ] Wait for DNS propagation (up to 48 hours)
- [ ] Enable SSL/TLS certificate in Azure
- [ ] Enable HTTPS redirect
- [ ] Test website at custom domain

## SEO & Search Engines

- [ ] Verify robots.txt is accessible (customfarmandgate.com/robots.txt)
- [ ] Verify sitemap.xml is accessible (customfarmandgate.com/sitemap.xml)
- [ ] Create Google Search Console account
- [ ] Submit sitemap to Google Search Console
- [ ] Create Bing Webmaster Tools account
- [ ] Submit sitemap to Bing Webmaster Tools
- [ ] Set up Google Business Profile (optional but recommended)

## Testing

- [ ] Test on desktop Chrome
- [ ] Test on desktop Firefox
- [ ] Test on desktop Safari
- [ ] Test on mobile iPhone/Safari
- [ ] Test on mobile Android/Chrome
- [ ] Test phone click-to-call on mobile
- [ ] Test 404 error page
- [ ] Verify favicon displays correctly
- [ ] Test PWA install prompt on mobile
- [ ] Check page load speed (Google PageSpeed Insights)
